📖 Quick Guide - How to Use Cascade Ledger

1 Choose Your Entry Mode

Toggle between Single Entry Mode (for one expense at a time) or Bulk Entry Mode (for multiple expenses at once).

💡 Tip: Use Single Entry for quick adds. Use Bulk Entry when processing multiple receipts.

2 Single Entry Mode - Manual Entry

  • Select Expense Type: Recurring (monthly bills) or Variable (one-time purchases)
  • Choose a Category from the dropdown (categories change based on expense type)
  • Fill in Date, Description, and Amount
  • For Variable expenses: Add Unit, Price, Quantity (amount auto-calculates)
  • Click "Preview" to check, then "Add to List"

3 Smart OCR - Scan Receipts Automatically

Click "📷 OCR Receipt" to activate receipt scanning:

  • Drag & drop images or PDFs into the dropzone
  • Or click to browse and select receipt files
  • The system automatically extracts: Amount, Date, Supplier, Description
  • Smart Auto-Categorization suggests the right category based on keywords
  • Review the preview and click "Add to List"

💡 Pro Tip: OCR works best with clear, well-lit receipt photos. Supports JPG, PNG, and PDF formats!

4 Paste Text - Quick Receipt Entry

Click "📋 Paste Text" to paste receipt text:

  • Copy text from digital receipts or screenshots
  • Paste into the text area
  • Click "Process Text"
  • System extracts amount, date, and supplier automatically

5 Bulk Entry Mode - Add Multiple Expenses

Switch to Bulk Entry Mode for processing multiple expenses:

  • 5 empty rows appear automatically when you open bulk mode
  • Click "➕ Add Row" to add more rows
  • Fill in each row: Date, Type, Category, Description, Amount
  • Categories auto-update when you select expense type
  • Click "🗑 Delete" to remove unwanted rows
  • Click "✅ Add to List" to move all valid entries to transaction list

💡 Note: Invalid rows (missing fields) will be highlighted in red and stay in the table for correction.

6 Transaction List - Review & Submit

All your entries appear in the Transaction List on the right:

  • Review each transaction before submitting
  • Click 🗑 Delete to remove unwanted items
  • See total count and amount at the top
  • Click "🚀 Submit to Ledger" to save all transactions to Google Sheet

💡 Auto-Save: Your transaction list is saved locally. It persists even if you refresh the page!

7 Settings - Customize Your Ledger

Click the ⚙️ Settings button to:

  • Enter admin password to unlock settings
  • Configure Vision API key (for OCR)
  • Configure Claude API key (for smart categorization)
  • Click "Test API Keys" to verify they work
  • Categories and property name are managed in the Google Sheet "Settings" tab

⚡ Quick Tips

  • Expense Types: Recurring = monthly bills (internet, utilities). Variable = one-time purchases (supplies, repairs)
  • Auto-Calculation: For Variable expenses, enter Price Per Unit × Quantity and amount calculates automatically
  • Smart Categories: OCR suggests categories based on keywords (e.g., "Meralco" → Utilities – Electricity)
  • Multiple Formats: Use any entry method that works best for you - they all go to the same transaction list!
  • Keyboard Shortcut: Press Tab to move between fields quickly
